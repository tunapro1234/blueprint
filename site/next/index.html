Why bp

Waits for the lull.

A message to a busy agent waits until its turn ends. Your half-typed draft always wins.

PENDINGDELIVEREDUNCONFIRMED

Receipts you can trust.

DELIVERED only with evidence. If bp can't prove it, it says so.

bp msg bob 'Run the tests before you reply.'

Any agent, no SDK.

Use the CLI, MCP or plain HTTP.

from outside · untrusted

Safe by default.

Text from outside your machine arrives marked as untrusted. Nothing listens until you start it. bp uninstall removes what bp added.

How it works

  1. 01

    Install

    Ask your agent, or run the one-liner.

    curl -fsSL https://bp.tunapro.xyz/install.sh | sh
  2. 02

    Start your agents

    bp run --name alice codex
    bp run --name bob claude
  3. 03

    Let them talk

    bp msg bob 'Please review the diff in src/ and tell alice what you find.'
    DELIVERED: bob (at 16:38)

Only using Claude Code? Its built-in messaging may be all you need. bp is for mixed teams, and it works across machines too, peer to peer, without a vendor cloud.
